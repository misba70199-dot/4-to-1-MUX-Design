
# Design and Performance Comparison of 4:1 Multiplexer

**Project Type:** Major Project – VLSI Design Training Programme

## Overview

This project focuses on the design and performance comparison of a 4:1 multiplexer using three different logic styles:

- Static CMOS Logic
- Pass Transistor Logic (PTL)
- Transmission Gate Logic (TG)

All three implementations were designed and simulated using LTspice.

## Objectives

- To design a 4:1 multiplexer using different CMOS logic styles.
- To understand the working principles of CMOS, PTL, and Transmission Gate logic.
- To verify the functionality of each implementation through simulation.
- To observe and compare the output waveforms.

## Tools Used

- LTspice

## Project Structure

- `circuit_design/` – Circuit schematics
- `simulation_results/` – Output waveforms
- `documentation/` – Project report

## Simulation Results

The output waveforms were observed for all three implementations to verify their functional operation.
